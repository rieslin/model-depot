# Model Depot 安装包对接说明

适用于用 Windows 安装包安装的 Model Depot 0.6.6。供需要使用本机 Model Depot、ComfyUI、模型库或本地语言模型的其他程序参考。安装包的制作方式见 `README.md`。

## 1. 安装后的文件夹

安装位置在安装时选择，默认为可用空间最大的磁盘上的 `Model Depot` 文件夹，下文记作 `<安装位置>`。

```
<安装位置>\
  app\                      Model Depot 程序；install.json 在此
  python\                   Model Depot 自用的 Python 3.14 嵌入版（含 aiohttp、Pillow）
  llm\llama.cpp\            本地语言模型的运行程序（llama.cpp，CUDA 13 版）
  llm\models\               本地语言模型文件（GGUF）
  ComfyUI\                  ComfyUI 便携版 0.42.5（Python 3.13、PyTorch cu130）与 5 个插件（ComfyUI-GGUF、PixAI 打标、
                            Impact Pack、Impact Subpack、controlnet_aux），以及 Visual C++ 运行库文件
    Start ComfyUI.cmd       ComfyUI 的快捷方式所启动的脚本：ComfyUI 已在运行时打开其网页，否则启动
    ComfyUI\user\default\workflows\
                            默认工作流：6 个官方模板（Z-Image、Krea 2、Qwen Image 2.1、Anima）
                            可选工作流：「可选工作流」文件夹，20 个
  Model Inbox\              待整理文件夹：放入的模型文件经确认后移入模型库（0.6.2 之前的安装为 models\，仍照常整理）
  data\                     Model Depot 的数据文件夹（可在安装时另选位置）
  uninstall\                卸载程序
```

使用自带的 ComfyUI 时，模型库默认为 `<安装位置>\ComfyUI\ComfyUI\models`，可在安装时另选位置。另选时，ComfyUI 的启动脚本（`run_*.bat`）带有 `--models-directory "<模型库>"`（路径含系统代码页无法表示的字符时，脚本以 UTF-8 写入并以 `chcp 65001` 开头）。SeedVR2 的模型与 VAE 放在 ComfyUI 的标准文件夹下的 `seedvr2` 子文件夹（`diffusion_models\seedvr2`、`vae\seedvr2`，ComfyUI 中写作 `seedvr2\文件名`）；0.6.2 起新安装不再登记 `SEEDVR2` 文件夹，此前的安装保留原有登记。提示词扩写模型（PE，Qwen-Image 2.1 所用）放在 `<模型库>\text_encoders\pe`，ComfyUI 中写作 `pe\文件名`；Model Depot 下载与整理时按指纹或确切大小放入，附带的工作流也这样引用。PixAI 打标模型位于 `<模型库>\taggers\pixai-tagger-v1.0`。

更新（运行新版安装包）只替换程序文件：ComfyUI 的 `user` 文件夹（设置与管理器配置）、启动脚本、`extra_model_paths.yaml` 不变；已安装的插件版本高于安装包时保留已安装的；工作流中用户未改动过的文件替换为新版，改动过的保留（`install.json` 的 `workflow_files` 记有安装时各文件的指纹）。卸载只删除安装包自带的插件（`install.json` 的 `own_custom_nodes`），其他插件保留在 `custom_nodes` 中。

安装时也可沿用本机已有的 ComfyUI 便携版（安装程序在各磁盘与用户文件夹中查找，也可手动选择）。此时：

- `<安装位置>` 中没有 ComfyUI 文件夹，`ComfyUIDir` 指向已有的 ComfyUI。
- 模型库即该 ComfyUI 的模型文件夹；其启动脚本带有 `--models-directory` 或 `--base-directory` 时，以脚本为准。
- 默认工作流与可选工作流放入该 ComfyUI 工作流列表中的「Model Depot」文件夹（可选工作流在其下的「可选工作流」文件夹），已有的同名文件不覆盖。
- 安装包中的模型（PixAI 打标模型）只在模型库中没有时补入。
- 该 ComfyUI 的其他文件、插件、启动脚本、`extra_model_paths.yaml` 与设置均不改动；它缺少的自带插件在安装时列出，由用户经 ComfyUI 管理器安装。卸载 Model Depot 时不删除它，也不删除它的快捷方式。

运行要求：NVIDIA RTX 20 系列或更新的显卡，驱动 580 或更新。

## 2. 查找已安装的 Model Depot

两处记录，内容一致：

1. 注册表 `HKCU\Software\Model Depot`，字符串值 `InstallDir`、`ComfyUIDir`、`LibraryDir`、`LlmDir`、`DataDir`、`Version`，以及 DWORD 值 `ComfyUIOwn`（1 为自带的 ComfyUI，0 为沿用已有的）。
2. `<安装位置>\app\install.json`：

```json
{
  "version": "0.6.6",
  "install_dir": "<安装位置>",
  "data_dir": "<数据文件夹>",
  "python": "<安装位置>\\python\\python.exe",
  "comfyui_dir": "<安装位置>\\ComfyUI 或已有 ComfyUI 的文件夹",
  "comfyui_own": true,
  "models_dir": "<模型库>",
  "llm_dir": "<安装位置>\\llm",
  "inbox": ["<安装位置>\\Model Inbox"],
  "inbox_once": ["<安装包旁的 Model Inbox 文件夹>"],
  "language": "zh",
  "own_custom_nodes": ["ComfyUI-GGUF", "..."],
  "workflow_files": {"<工作流的相对路径>": "<SHA-256>"}
}
```

卸载项位于 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\ModelDepot`。安装与卸载均针对当前用户，无需管理员权限。卸载时上述注册表项一并删除。

## 3. 可以直接使用的部分

| 内容 | 使用方式 |
|---|---|
| ComfyUI | Python 为 `<ComfyUIDir>\python_embeded\python.exe`，入口为 `<ComfyUIDir>\ComfyUI\main.py`，工作目录为 `<ComfyUIDir>`，参数 `--windows-standalone-build --enable-manager`。`LibraryDir` 与 `<ComfyUIDir>\ComfyUI\models` 不同时，另加 `--models-directory "<LibraryDir>"`。沿用已有的 ComfyUI 时（`ComfyUIOwn` 为 0），按其自己的启动脚本中的参数启动 |
| 模型库 | `LibraryDir`，按 ComfyUI 的模型类型分子文件夹 |
| 模型资料与推荐参数 | Model Depot 的接口，默认地址 `http://127.0.0.1:8194`，以 `<DataDir>\server.json` 中的端口为准。接口位于 `/api/v1/` 之下，收发 JSON：`GET /api/v1/models` 模型清单，`GET /api/v1/models/{sha256}` 单个模型，`GET /api/v1/models/{sha256}/card` 推荐参数（资料卡），`GET /api/v1/companions` 各系列配套文件的参考清单，`GET /api/v1/events` 变化通知。缺少文件时，可打开 `http://127.0.0.1:8194/#/download?link=<文件链接>`，由用户在 Model Depot 的下载抽屉中确认下载 |
| 本地语言模型 | `<LlmDir>\llama.cpp\llama-server.exe` 与 `<LlmDir>\models\*.gguf` |

## 4. 对接程序的建议做法

1. 先查 `HKCU\Software\Model Depot`。已安装时，使用其中的 ComfyUI、模型库与本地语言模型，不另装第二套。
2. 未安装时，提示用户先安装 Model Depot。用户不安装时，对接本机已有的 ComfyUI 与语言模型；两者都没有时，提示下载 ComfyUI 便携版并引导配置。
3. 对接程序自己的 ComfyUI 插件由对接程序安装到 `<ComfyUIDir>\ComfyUI\custom_nodes`。
4. 对接程序自己的工作流放在 `<ComfyUIDir>\ComfyUI\user\default\workflows` 下以该程序命名的文件夹中，不改动根目录的默认工作流、「可选工作流」文件夹与「Model Depot」文件夹。

## 5. 自带的 ComfyUI 与常见便携版的差异

- `numba` 为 0.68.0、`llvmlite` 为 0.50.0（ComfyUI 便携版附带的 numba 0.65 不支持 NumPy 2.5）；另装 `gguf`，供 ComfyUI-GGUF 使用。
- 附 Visual C++ 运行库文件（`python_embeded` 中、`torch\lib` 中），未安装 Visual C++ 运行库的电脑也能启动。
- ComfyUI 管理器的更新方式为稳定版（`update_policy = stable-comfyui`）。
- 不含模型、输出、输入、日志与缓存，也不含开发电脑的 ComfyUI 设置；`impact-pack.ini` 由插件在首次启动时按安装位置生成。
- 可选工作流的输出节点为「保存图像」，文件名前缀 `ComfyUI`。
