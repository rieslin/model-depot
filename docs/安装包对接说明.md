# Model Depot 安装包对接说明

适用于用 Windows 安装包安装的 Model Depot 0.6.0。供需要使用本机 Model Depot、ComfyUI、模型库或本地语言模型的其他程序参考。安装包的制作方式见 `README.md`。

## 1. 安装后的文件夹

安装位置在安装时选择，默认为可用空间最大的磁盘上的 `Model Depot` 文件夹，下文记作 `<安装位置>`。

```
<安装位置>\
  app\                      Model Depot 程序；install.json 在此
  python\                   Model Depot 自用的 Python 3.14 嵌入版（含 aiohttp、Pillow）
  llm\llama.cpp\            本地语言模型的运行程序（llama.cpp，CUDA 13 版）
  llm\models\               本地语言模型文件（GGUF）
  ComfyUI\                  ComfyUI 便携版 0.37.0（Python 3.13、PyTorch 2.14.0 cu130）与 12 个插件
    ComfyUI\user\default\workflows\
                            默认工作流：7 个官方模板（Z-Image、Krea 2、Qwen Image 2.1、Anima）
                            可选工作流：「可选工作流」文件夹，20 个
  models\                   待整理文件夹：放入的模型文件经确认后移入模型库
  data\                     Model Depot 的数据文件夹（可在安装时另选位置）
  uninstall\                卸载程序
```

模型库默认为 `<安装位置>\ComfyUI\ComfyUI\models`，可在安装时另选位置。另选时，ComfyUI 的启动脚本（`run_*.bat`）带有 `--models-directory "<模型库>"`。PixAI 打标模型位于 `<模型库>\taggers\pixai-tagger-v1.0`。`<安装位置>\ComfyUI\ComfyUI\extra_model_paths.yaml` 登记了 `<模型库>\SEEDVR2`。

运行要求：NVIDIA RTX 20 系列或更新的显卡，驱动 580 或更新。

## 2. 查找已安装的 Model Depot

两处记录，内容一致：

1. 注册表 `HKCU\Software\Model Depot`，字符串值 `InstallDir`、`ComfyUIDir`、`LibraryDir`、`LlmDir`、`DataDir`、`Version`。
2. `<安装位置>\app\install.json`：

```json
{
  "version": "0.6.0",
  "install_dir": "<安装位置>",
  "data_dir": "<数据文件夹>",
  "python": "<安装位置>\\python\\python.exe",
  "comfyui_dir": "<安装位置>\\ComfyUI",
  "models_dir": "<模型库>",
  "llm_dir": "<安装位置>\\llm",
  "inbox": ["<安装位置>\\models"],
  "inbox_once": ["<安装包旁的 models 文件夹>"],
  "language": "zh"
}
```

卸载项位于 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\ModelDepot`。安装与卸载均针对当前用户，无需管理员权限。卸载时上述注册表项一并删除。

## 3. 可以直接使用的部分

| 内容 | 使用方式 |
|---|---|
| ComfyUI | Python 为 `<ComfyUIDir>\python_embeded\python.exe`，入口为 `<ComfyUIDir>\ComfyUI\main.py`，工作目录为 `<ComfyUIDir>`，参数 `--windows-standalone-build --enable-manager`。`LibraryDir` 与 `<ComfyUIDir>\ComfyUI\models` 不同时，另加 `--models-directory "<LibraryDir>"` |
| 模型库 | `LibraryDir`，按 ComfyUI 的模型类型分子文件夹 |
| 模型资料与推荐参数 | Model Depot 的接口，默认地址 `http://127.0.0.1:8194`，以 `<DataDir>\server.json` 中的端口为准。接口位于 `/api/v1/` 之下，收发 JSON：`GET /api/v1/models` 模型清单，`GET /api/v1/models/{sha256}` 单个模型，`GET /api/v1/models/{sha256}/card` 推荐参数（资料卡），`GET /api/v1/events` 变化通知 |
| 本地语言模型 | `<LlmDir>\llama.cpp\llama-server.exe` 与 `<LlmDir>\models\*.gguf` |

## 4. 对接程序的建议做法

1. 先查 `HKCU\Software\Model Depot`。已安装时，使用其中的 ComfyUI、模型库与本地语言模型，不另装第二套。
2. 未安装时，提示用户先安装 Model Depot。用户不安装时，对接本机已有的 ComfyUI 与语言模型；两者都没有时，提示下载 ComfyUI 便携版并引导配置。
3. 对接程序自己的 ComfyUI 插件由对接程序安装到 `<ComfyUIDir>\ComfyUI\custom_nodes`。
4. 对接程序自己的工作流放在 `<ComfyUIDir>\ComfyUI\user\default\workflows` 下以该程序命名的文件夹中，不改动根目录的默认工作流与「可选工作流」文件夹。

## 5. 与常见 ComfyUI 便携版的差异

- `numba` 为 0.68.0、`llvmlite` 为 0.50.0。ComfyUI 便携版附带的 numba 0.65 不支持 NumPy 2.5，会导致 was-node-suite-comfyui 插件无法加载。
- 不含模型、输出、输入、日志与缓存；`was_suite_config.json`、`impact-pack.ini` 由插件在首次启动时按安装位置生成。
- 可选工作流的输出节点为「保存图像」，文件名前缀 `ComfyUI`。
